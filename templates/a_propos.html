Présentation

SAÉ 2.01 - Développement d'une application web

Nom du projet

DataSanté

DataSanté est une application web de visualisation des données de santé en France. Elle permet de consulter des effectifs, densités, indicateurs territoriaux et comparaisons à partir d'un formulaire, d'une carte interactive et de graphiques.

Objectifs

SAÉ
  • Construire une application Flask organisée selon l'architecture MVC.
  • Exploiter la base SAE 2.04 pour alimenter les listes et référentiels.
  • Interroger l'API Data Ameli pour afficher des données de santé réelles.
  • Proposer des tableaux, graphiques, indicateurs et comparaisons lisibles.

Technologies utilisées

Stack
  • HTML, CSS et JavaScript pour l'interface.
  • Flask, Jinja2 et Blueprints pour le serveur web.
  • SQL, SQLAlchemy et SQLite/MySQL pour les données de référence.
  • API Data Ameli, Fetch API, Chart.js, Leaflet et GeoJSON.

Sources de données

Références
  • Base SAE 2.04 : régions, départements, professions et postes de prescription.
  • API publique Data Ameli : effectifs, honoraires, prescriptions et pathologies.
  • GeoJSON des régions françaises pour la carte interactive.

Architecture

MVC

Le projet sépare clairement les responsabilités : les modèles SQLAlchemy sont dans models/, les routes Flask dans controllers/, les appels à l'API dans services/, les pages Jinja2 dans templates/, et les fichiers CSS/JavaScript/GeoJSON dans static/.
